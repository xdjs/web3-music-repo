# Inline original lyrics

The schema 5 extractor retains literal lyric text from `lyrics`, `lyrics.text`, and those same fields under `body` and `properties`. It preserves internal line breaks, normalizes CRLF, and deduplicates repeated root/body/property copies. Distinct explicit variants remain separate. URL-only values and empty/placeholder values are not treated as recovered text; oversized text is reported as omitted rather than silently truncated. A record's combined lyric text is bounded at 100 KiB UTF-8.

`src/lyrics-ui.mjs` renders the recovered text on the song page. Short text displays directly; longer text uses a four-line/280-character preview and native keyboard-accessible disclosure. Opening it hides the preview and reveals the complete retained text; closing restores the preview. It reuses the existing reading, artist-sources and original-lyrics styles. Every text value is escaped; no source HTML is executed. The secondary source link accepts only HTTP(S), rejects URL credentials, and distinguishes original metadata/release pages from explicitly indexed Spinamp metadata. Listeners do not need to leave the song page to read available lyrics.

`node scripts/recover-cached-lyrics.mjs` reads only local original documents and writes an additive lyrics recovery artifact and audit. It does not fetch gateways or change the active worker's data. At the November 6 snapshot, it matched 9,199 of 9,825 current app records to original documents: all 4,915 Sound, all 4,036 Catalog, all 162 Mint Songs and the available other cached sources. **1,275 Sound records have actual lyric text.** None of the inspected explicit Catalog or Mint Songs lyric fields contained text. This is a field-recovery count, not a claim that the other recordings have no lyrics. The prior worker retained only `hasLyrics`, discarding the text; the source cache already contained these texts.

The audit did not fetch 616 Supercollector release sources again; their preserved public search payload was inspected separately and had no lyric fields. Spinamp additions made after this snapshot require their own updated count. The renderer supports attributed Spinamp text, but those lyrics are not claimed as verified against a current contract metadata document.

Outputs: `data/lyrics-recovery.json` maps document-matched record IDs to recovered lyric fields and original-source provenance. `data/lyrics-recovery-audit.json` contains counts and sample record IDs, without quoting song lyrics. The parent metadata worker should re-extract cached documents under schema 5 and clear stale schema 4 `hasLyrics` fields when no actual text survives validation. Do not blindly overwrite the rest of each musicMetadata record with the lyric-only artifact.

Focused tests cover newline preservation, duplicate/variant roots, URL-only and placeholder values, UTF-8 size limits, malicious markup, unsafe source URLs, short/long rendering and index attribution. Browser styling/keyboard QA belongs to the integrated app revision; its report is recorded separately before release.
